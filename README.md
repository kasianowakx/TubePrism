# TubePrism

TubPrism utilizes high-performance, distributed processing architecture to enable real-time and auto-scaling for efficient load balancing across multiple processors.

The key benefits of using TubePrism include:

- TubPrism utilizes high-performance, distributed processing
- architecture to enable real-time and
- auto-scaling for efficient load balancing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TubePrism.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

TubePrism is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
